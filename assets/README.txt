HERITAGE WALK - FLUTTER ASSET PACK

branding/
  User-provided Heritage Walk logo + resized PNG variants.

icons/navigation/
  Bottom navigation icons.

icons/actions/
  CRUD and common UI action icons.

icons/categories/
  Fort, temple, museum and nature category icons.

icons/support/
  Help/info icons.

placeholders/
  Neutral fallback images. Replace these with licensed/owned real Sri Lankan

    - assets/icons/support/
    - assets/placeholders/
